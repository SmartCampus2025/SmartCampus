# SmartCampus GitHub Setup Package

This archive is arranged so the project contents sit at the repository root:

- backend/
- frontend/
- mobile/
- README.md
- .gitignore
- .env.example

Important:
- The real backend/.env file was intentionally excluded because it contained secrets.
- Create your real environment configuration locally after cloning/downloading the repository.
- Do not commit real credentials to GitHub.
- This package rearranges the existing project only; it does not claim to fix the existing code bugs.
